ZELO Admin Project 1 - Setup

1. Copy the admin_project1 folder into E:\xampp\htdocs\.
2. Start Apache and MySQL from XAMPP.
3. Open phpMyAdmin.
4. Import dashboard\admin.sql. The script creates the hoteldb database and all required tables.
5. Open http://localhost/admin_project1/dashboard/
6. Demo admin login:
   Email: admin@zelo.com
   Password: Admin@123
7. You can also create a new account from Registration.

Database: hoteldb
Main tables: users, room_type, rooms, bookings, reviews
